# SoulBridge UI/UX Design System Runbook

## Design Standards

1. **Aesthetic Tone**: Premium, mature, trustworthy, and welcoming dating platform design.
2. **Framework**: Tailwind CSS v4 with custom gradients and utility classes.
3. **Accessibility**: Minimum 4.5:1 text contrast ratio and 44x44px minimum touch targets.
4. **Motion**: Use Framer Motion / GSAP for smooth transitions while honoring `prefers-reduced-motion`.
5. **Preservation**: Never alter business logic, form actions, or data flow when performing visual styling updates.
